## ¿Qué son estas plantillas?

Colección de **5 plantillas SQL y dashboards Streamlit** gratuitas para
[Sage50BI](https://pedironline.com), la solución de Business Intelligence para Sage50 de ALCA TIC.

Cada plantilla incluye:
- 📊 Consultas SQL optimizadas para Sage50
- 🐍 Dashboards interactivos con Streamlit
- 🎥 Vídeos explicativos en YouTube
- 🔄 Actualización automática desde la aplicación
- 📦 Packs temáticos para instalar varias a la vez

### ¿Para quién son?

- **Gestores administrativos** que usan Sage50 y necesitan informes personalizados
- **Contables** que quieren automatizar listados, balances y facturas
- **Empresas** que buscan dashboards de sus datos de Sage50 sin programar
- **Consultores SAP/Sage** que necesitan plantillas listas para usar
